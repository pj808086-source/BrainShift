# Brain Shift v2.0
Offline-first Android focus app for CA/CMA practice.

Features:
- Clear mobile UI
- One challenge at a time
- Daily 20-challenge routine
- XP and levels
- Score and streak
- Finance, Quant, Logic and focus-style challenges
- Local progress
- No ads
- No internet permission
- No camera, microphone or location permissions

Build with an Android Gradle environment.
Application ID: com.brainshift.app
